# 页面与布局规格 v0.3

> 目标：640×480dp（RP Duo）为主，538×469dp（Thor）为窄版；单屏 832×468dp。
> 所有页面遵循 [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)、[FEATURE-MAP.md](FEATURE-MAP.md) 与 [../INPUT-AND-FOCUS.md](../INPUT-AND-FOCUS.md)。

## 1. 信息架构

```text
主机 ──→ 详情 / 添加 / 配对 / 主机操作
  │
  ├─→ 应用 ──→ 应用操作 / 串流
  ├─→ 远程（EasyTier 状态 / 配置 / PC 配置 / 手动添加）
  └─→ 设置（画面/音频/输入/网络/主机/界面/关于）

串流 ──→ 控制台（状态 / 画面 / 音频 / 输入 / 连接）
  ├─→ 工具（触摸板 / 键盘 / 快捷键）
  └─→ 确认层 / 错误层 / 退出
```

- Rail：主机 / 应用 / 远程 / 设置。
- 串流时隐藏 Rail；下屏变控制台。
- 设置是独立一级，不塞进“更多”；7 类分类见第 6 节。
- 配对/添加/编辑/应用操作是 Sheet 或二级页，不新增一级入口。
- 所有上游功能的落位与“不做”清单见 [FEATURE-MAP.md](FEATURE-MAP.md)。

## 2. 全局壳层

### 2.1 浏览态

```text
640×480
┌──────┬─────────────────────────────────────┐
│ Rail │ AppBar 44dp                         │
│ 64dp ├─────────────────────────────────────┤
│      │ Content 576×408dp                   │
│      │                                     │
│      ├─────────────────────────────────────┤
│      │ ModeBar 28dp                        │
└──────┴─────────────────────────────────────┘
```

- Rail 64；AppBar 44；ModeBar 28；内容 576×408。
- 页面左右 12dp；区块 16dp；卡片 8dp。
- 首屏必须有一个可见焦点环。

### 2.2 串流态

```text
640×408（无 Rail）
┌─────────────────────────────────────────────┐
│ 书房台式机   ● 1080p60 · 18ms      [直通]   │ 44
│ [控制台] [工具]                    Y 切换  │ 30
├──────────────────────┬──────────────────────┤
│ 左栏 220dp            │ 右栏 384dp           │
│ 连接摘要/快捷操作      │ 状态/画面/音频/输入/连接 │
│                      │                      │
├──────────────────────┴──────────────────────┤
│ ● 手柄：直通电脑          RETURN 本地菜单    │ 28
└─────────────────────────────────────────────┘
```

- 左栏 220dp：分辨率/帧率/码率、延迟/丢包、音量、HDR、输入模式、本地菜单。
- 右栏 384dp：5 个 tab（状态/画面/音频/输入/连接）+ 内容；状态置首并默认。
- 顶部 30dp 为“控制台 / 工具”双态开关；工具态隐藏左右栏，工具内容占满 616dp。
- 直通时无焦点环，控制台可降不透明度 60%；触摸进入本地。
- 本地时 100%，焦点环可见；A 在根层恢复直通。

## 3. 主机

### 3.1 布局

```text
┌──────┬─────────────────────────────────────┐
│ 主机 │ 主机                         +  ⟳   │
│ 应用 ├──────────────────────┬──────────────┤
│ 远程 │ 书房台式机      LAN  │ 书房台式机    │
│ 设置 │ 192.168.1.20 已配对  │ 已配对       │
│      │----------------------│ 192.168...   │
│      │ 客厅小主机      远程 │ 最近 2 分钟  │
│      │ 10.0.0.2 未配对      │              │
│      │                      │ [连接]       │
│      │                      │ [配对]       │
│      │                      │ [应用] [编辑]│
├──────┴──────────────────────┴──────────────┤
│ ● 手柄：下屏        B 连接 · A 返回          │
└─────────────────────────────────────────────┘
```

- 左列表 320dp；右侧详情 244dp；gap 12dp。
- 窄版 538：列表全宽；选中后详情覆盖层（或用顶部详情卡）。
- 主机行 88dp；状态点 + 名称 + 地址/状态 + 标签。
- 详情：名称、地址、状态、最近连接、操作。
- 操作：连接、配对、应用、编辑、删除（危险，二次确认）。
- 空态：“还没有主机” + 添加/刷新。
- 加载：骨架 3 行。
- 错误：原因 + 重试。

### 3.2 添加/配对

- 手动添加：IP/端口输入，数字键盘/ASCII；校验；连通性检查。
- PIN 配对：4 位 PIN 大号显示 + “在电脑上的 Foundation Sunshine 输入此 PIN”。
- QR：有摄像头时显示扫码；否则隐藏或粘贴链接。
- 配对状态：等待、配对中、成功、失败（PIN 错/已配对/离线）。

### 3.3 主机详情与操作

详情面板（右栏，窄屏 Sheet）固定分区：

```text
名称 / 状态点 / LAN·远程·手动
地址 · 配对状态 · 最近连接
[继续串流 / 配对 / 唤醒 / 应用列表]
[应用列表] [主机操作]
主机操作：恢复上次会话 / 唤醒 / 重新配对 / 网络测试 /
          休眠 / 退出应用 / WebUI / IPv6 / 删除
```

- 主操作最多两个按钮，避免详情栏变成按钮墙。
- 运行中主机优先显示“继续串流”；未配对显示“配对”；离线显示“唤醒”；已配对在线且无运行中应用时主按钮直接用“应用列表”。
- 如果主按钮已经是“应用列表”，不再重复显示第二个“应用列表”；只保留“主机操作”。
- 重新配对、网络测试、删除只在“主机操作”里出现，不在详情栏重复。
- 删除、休眠、退出应用、断开必须二次确认。
- 多地址主机在连接前打开地址选择 Sheet；记住上次选择。
- 网络测试合并普通延迟/丢包测试与 Sunshine 质量探测：结果页显示延迟、抖动、丢包、建议码率；“应用到本次串流”或“保存为默认”。
- WOL 仅在离线且有 MAC 时可用；没有 MAC 时隐藏并说明。
- WebUI 放进“主机操作”，不占主操作位；自动解锁在串流工具页“解锁”中完成。

### 3.4 主机操作 Sheet 与筛选

- 长按/手柄 X 打开主机操作 Sheet；内容与详情面板“主机操作”一致，避免两套文案。
- 主机页 AppBar 右侧保留：添加、刷新；应用列表入口在详情栏，不在 AppBar 重复。
- 主机页顶部提供筛选：全部 / 已配对 / 未配对；列表默认在线 → 已配对 → 名称排序。
- 恢复上次会话放在“主机操作”；网络诊断从主机操作进入。
- 列表行 88dp；运行中显示金色运行徽章；未配对显示锁；离线整体 45% 透明度。
- 空态：一句“还没有主机” + 添加/刷新两个主操作。


## 4. 应用

```text
┌──────┬─────────────────────────────────────┐
│ 应用 │ 应用                            ⇅  ⟳ │
│      ├─────────────────────────────────────┤
│      │ [icon] 游戏 A   [icon] 游戏 B       │
│      │ [icon] 桌面     [icon] 工具         │
│      │                                     │
│      │ 选中应用详情：名称/路径/最近启动     │
│      │ [启动串流]                           │
├──────┴─────────────────────────────────────┤
│ ● 手柄：下屏        B 启动 · A 返回          │
└─────────────────────────────────────────────┘
```

- 640：3 列；538：2 列；每卡 120–160dp 高。
- 应用列表始终按当前主机加载；多台在线已配对主机时，顶部显示主机切换 chips，绝不把不同主机的应用混在一个网格里。
- AppBar 主标题固定为“应用”，不拼接主机名；主机区分放在页内标题和切换 chips。
- 页内标题显示当前主机名，避免只看到应用名却分不清来源。
- 图标 56dp；无图标用首字母/几何占位。
- 选中卡金边 + 12% 背景；上屏只读显示选中应用的真实图标/名称，图标未加载时才回退首字母占位。
- B 启动；详情卡有“启动串流”。
- 主机未选/离线：空态 + 去主机页。

### 4.1 应用操作

- 单击/A：无运行应用直接启动；有其它应用运行则打开操作 Sheet。
- 长按/X：操作 Sheet：
  - 启动 / 继续
  - 使用上次设置启动
  - 退出当前应用并启动
  - 退出当前应用
  - 隐藏 / 取消隐藏
  - 应用详情
  - 创建桌面快捷方式
- 详情：App ID、HDR 支持、命令列表、上次分辨率/FPS/码率/HDR、上次启动。
- “上次设置”只影响启动参数，不覆盖全局默认设置。
- 隐藏应用默认不出现在网格；AppBar 筛选“显示已隐藏”后以 40% 透明度显示。
- 应用页不新增搜索/收藏/拖拽排序；主机返回顺序即顺序。


## 5. 远程

```text
┌──────┬─────────────────────────────────────┐
│ 远程 │ EasyTier                     ● 已连接│
│      ├──────────────────────┬──────────────┤
│      │ 网络名  family-net   │ 本机 IP      │
│      │ 密钥    ••••••••     │ 10.0.0.1/24  │
│      │ Peer    public...    │ 节点 2       │
│      │ [启动/停止]          │ 延迟 18ms    │
│      │ [复制 PC 配置] [QR]  │              │
│      ├──────────────────────┴──────────────┤
│      │ 手动添加主机 IP [10.0.0.2] [添加]    │
├──────┴─────────────────────────────────────┤
│ ● 手柄：下屏     B 操作 · A 返回             │
└─────────────────────────────────────────────┘
```

- 左侧配置 320dp；右侧状态 244dp；窄版上下堆叠。
- 密钥默认掩码；按 A/长按确认后临时显示；复制 PC 配置时提示包含密钥。
- PC 配置：复制 TOML、显示 QR、说明“PC 用 .2”。
- 状态：未启动、等待权限、等待节点、已连接、错误。
- 手动添加主机：预填 PC 虚拟 IP 示例。

### 5.1 远程页分区

```text
[配置卡 ~320dp]  EasyTier · Android 内置客户端      [未启动]
                 网络名 / 网络密钥（遮罩） / 本机虚拟 IP
                 Peer / PC 虚拟 IP 10.0.0.2/24
                 [启动 EasyTier] [编辑]
                 [复制 PC 配置] [二维码] [高级]
[状态卡]          连接状态  未启动 / 已连接            ●
                 本机 ── EasyTier ── PC
                 节点 / 延迟 / 丢包
[手动添加]        10.0.0.2                          [添加]
```

- 左侧配置约 320dp，右侧状态占剩余宽度；窄版上下堆叠。
- 密钥默认掩码；按 A/长按确认后临时显示；复制 PC 配置时提示包含密钥。
- PC 配置不再单独成卡：复制 TOML、显示 QR 收进配置卡底部按钮；说明“PC 用 .2”。
- 状态：未启动、等待权限、启动中、已连接、错误。
- 状态卡只读；节点/延迟取 EasyTier 运行时真实值，无数据显示“—”；丢包没有数据源，固定显示“—”，不伪造 0.0%。
- 编辑配置与高级 flags 是设计稿未体现的入口，作为配置卡次要按钮保留。
- 手动添加主机：预填 PC 虚拟 IP 示例 10.0.0.2。

### 5.1 远程页分区

```text
[配置卡]  EasyTier + 状态 pill
          网络名 / 密钥（遮罩） / 本机虚拟 IP / Peer / PC 虚拟 IP
          [启动/停止 EasyTier] [编辑]
          [复制 PC 配置] [二维码] [高级]
[状态卡]  连接状态大字 + 状态点
          本机 ↔ EasyTier ↔ PC 示意图
          节点 / 延迟 / 丢包
[手动添加] 10.0.0.2              [添加]
```

- 启动前检查 VPN 授权；拒绝后状态“待授权”，保留重试。
- 状态卡只读 + 一个主按钮；配置卡进入编辑 Sheet，不把 10 个输入框直接铺在页面上。
- 高级 flags：smoltcp、延迟优先、禁 P2P、私有模式、禁 IPv6、KCP/QUIC、系统代理、禁加密、禁打洞；默认折叠。
- 复制/QR 使用 `.2` 配置；密钥明文只出现在剪贴板/二维码内容中，屏幕不显示。
- 未配置时显示内置模板，并提供“恢复默认”二次确认。


## 6. 设置

```text
┌──────┬─────────────────────────────────────┐
│ 设置 │ 设置 · 画面                          │
│      ├─────────────────────────────────────┤
│ 画面 │ 分辨率        原生 · 1920×1080    › │
│ 音频 │ 帧率          60 Hz               › │
│ 输入 │ 码率          20 Mbps             › │
│ 网络 │ 智能码率      [关]                  │
│ 主机 │ 视频格式      自动                › │
│ 界面 │ HDR           [关]                  │
│ 关于 │ 显示缩放      100%                › │
│      │ 高级          显示与布局 · …       › │
├──────┴─────────────────────────────────────┤
│ ● 手柄：下屏     B 调整 · A 返回             │
└─────────────────────────────────────────────┘
```

- 左分类 104dp；右内容 476dp；分类行 44dp。
- 分类固定：**画面 / 音频 / 输入 / 网络 / 主机 / 界面 / 关于**（7 类）。
- 分类获得焦点即切换内容（D-027）；右侧首行可聚焦；A 打开选项/子页，←/→ 微调。
- 一级页按 D-044 直接展示 `docs/ui/prototype/index.html` 中的选项行，不设“串流画质 / 输出 / 手柄”等中间父级；行顺序与设计稿一致。
- 设计稿未体现的上游高级项收进每类末尾唯一的“高级”行；高级子页沿用面包屑 + 返回，并用同一套行样式列出原有子页入口。主机类的“断开后锁屏”等少量未覆盖项直接放在该高级页。
- 行：标题 + 说明 + 值/开关；选中金边/12% 背景。
- 设置项保存即时；需要重连的项在标题旁标“重连”。
- 危险操作（重置、删除、退出）二次确认。
- 分辨率/帧率/码率/视频格式等枚举值使用与设计稿一致的选项浮层，不铺满一级页。

### 6.1 画面

- 串流画质：分辨率、帧率、码率、智能码率、ABR 模式、视频格式、HDR/模式、帧节奏、FEC（高级）、主机渲染缩放（高级）。
- 显示与布局：拉伸、画面位置九宫格、偏移 X/Y、反向分辨率、外接显示器、PiP、显示缩放。
- 性能浮层：开关、样式（迷你/标准/详细）、位置/方向、透明度、指标多选、串流后提示。
- 实验性：帧生成（DLL 状态/导入、质量、自适应）、PyroWave 诊断、解码缓冲/HEVC 低延迟/输出队列。
- 能力诊断入口；不可用项隐藏或灰显并说明原因。
- 所有画面项都标注是否需要重连；串流中修改不直接改当前会话时，提示“下次串流生效”。
- 一级页直接显示分辨率、帧率、码率、智能码率、视频格式、HDR、显示缩放；性能浮层只在 full 版显示。显示与布局、性能浮层细节、实验性收进“高级”。

### 6.2 音频

- 声道（立体声/5.1/7.1/7.1.4）。
- 音频直通：开关、编码（自动/Opus/AC3/EAC3/PCM）、缓冲、AC3 IEC61937。
- 空间音频/音效开关（设备支持时）。
- 麦克风：启用、初始状态、码率、增益/平衡/人声增强、按钮位置/颜色。
- 音频振动：开关、强度、路由（设备/手柄/两者）、场景。
- 波形触觉测试（P2）。
- 主机音频放在“主机”类，不在这里重复。
- 一级页直接显示声道、音频直通、麦克风、空间音频；音频振动属于已移除的 Game Menu 调参能力，minimal 版不显示。直通编码/缓冲/AC3、麦克风音质/增益、系统音效收进“高级”。

### 6.3 输入

- 手柄：死区、震动模式、多手柄/JoyCon、翻键/Guide、摇杆校准、手柄诊断、手柄鼠标模拟、体感/陀螺仪、DS5/实验触觉、USB 驱动。
- 触控：触摸模式（增强/经典/触控板/原生）、指针速度、增强分区/分隔线、双击拖拽/阈值、触控板灵敏度/预设。
- 键盘与鼠标：ESC 菜单键、远程 IME 自动弹出、触屏键盘自动唤起、鼠标轴修正/中键/滚轮、硬件触控板。
- 虚拟手柄：显示、布局、仅 L3/R3、Guide、半高竖屏、透明度、重置。
- 不提供 Shizuku/root 注入；相关上游项不显示。
- 一级页直接显示摇杆死区、震动模式、触摸模式、触控板速度、陀螺仪、虚拟手柄（full）、ESC 菜单键；多手柄/JoyCon/翻键、触控细节、键鼠修复、体感回退收进“高级”。

### 6.4 网络

- EasyTier 摘要 + “打开远程页”。
- STUN 开关。
- 网络测试：选择主机 → 延迟/抖动/丢包/建议码率 → 应用/保存。
- 手动添加主机入口。
- IPv6 在主机详情高级项，不在全局重复。
- iPerf3/WebUI 收进网络测试高级页（P2）。

### 6.5 主机

- SOPS 主机优化、屏幕组合模式、主机音频、仅控制流。
- 退出行为（停止主机应用/仅断开）、断开后锁屏、后台串流行为。
- 剪贴板同步文本/图片；不做文件传输。
- 自动解锁（P2）、WebUI（P2）。
- 一级页按设计稿直接显示 SOPS、屏幕组合、主机音频、仅控制流、退出行为、后台串流、剪贴板文本/图片；“断开后锁屏”和主机端能力说明收进“高级”。

### 6.6 界面

- 语言：MVP 锁定简体中文；显示“简体中文（MVP）”。
- 主题：锁定深色 + Lumen Gold；不提供粉色/背景取色/启动图标变体。

## 7. 串流控制台

> 实现注记（2026-11-20，`49631345`）：生产控制台由 `Game` 自己持有下屏 Presentation；直通/本地用窗口焦点切换，触摸下屏进入本地。单屏无下屏时改为 `Game` 窗口内 60% 面板 + compact 控制台，42% 快捷摘要尚未实现。状态、输入与限制见 `docs/STREAM-CONSOLE.md`。

### 7.1 画面 tab

- 会话信息：当前分辨率/帧率/码率/HDR/编码只读摘要。
- 分辨率：原生/720p/1080p/1440p/2160p/自定义 → 选择 Sheet；热切换失败自动回退重连。
- 帧率：30/60/90/120/设备刷新率/自定义 → 选择 Sheet。
- 屏幕模式/主机显示器：主机默认/不操作/自动激活/主屏/副屏/独占/VDD。
- 码率：滑杆 0.5–100 Mbps（PyroWave 可到 800）+ 当前值；松手提交。
- 智能码率/ABR：开关 + 质量/均衡/低延迟三档。
- HDR：真实 HDR 只读当前值 + “下次重连生效”说明；Window HDR 快捷动作在工具/快捷键动作条。
- 显示缩放：100% 滑杆 + 应用；拉伸/画面位置走设置页，运行时只读摘要。
- 性能浮层：隐藏/浮动/锁定三态 + 样式（M3 接入后可用）。
- 需要重连的项统一标“应用并重连”；不直接改主机设置。

### 7.2 音频 tab

- 本机音量滑杆 + 静音（控制下屏设备 `AudioManager`，不是主机音量）。
- 声道：立体声/5.1/7.1/7.1.4；切换提示“应用并重连”。
- 音频直通：开关 + 编码/缓冲（设置页；运行中只读或提示重连）。
- 麦克风：开关、设备、码率、增益；麦克风按钮不浮在视频上。
- 音频振动：开关、强度、路由（设备/手柄/两者）、场景。
- 主机音频：只读当前值 + “前往主机设置”。
- 波形触觉测试（P2）。
- minimal 版隐藏音频振动与波形触觉（Game Menu 调参能力已移除）；本机音量/静音使用 `AudioManager`，不走主机音量。

### 7.3 输入 tab

- 输入模式：直通电脑/本地菜单，只读状态 + “进入本地/恢复直通”。
- 触摸模式：增强/经典/触控板/原生；切换立即生效并影响工具/触摸板。
- 指针速度/触控板灵敏度：滑杆 + 预设（保存/应用/管理）。
- 陀螺仪：开关、鼠标模式、激活键、灵敏度、X/Y 反转。
- 虚拟手柄：显示/隐藏、布局、透明度。
- 手柄鼠标模拟：开关 + 速度。
- 震动：模式/强度。
- 键盘：本地键盘/主机键盘快捷入口。
- 死区：滑杆（P1）。
- USB 设备：放在连接 tab，不重复。

### 7.4 连接 tab

- 主机：名称、地址、配对状态、会话时长。
- 链路：RTT、抖动、丢包、带宽、网络延迟/解码/渲染/主机延迟；主机段缺失显示“未提供”。
- EasyTier：运行状态、虚拟 IP、网络名；“打开远程页”（本地模式）。
- USB：设备列表、共享/释放、自动共享（P1）。
- 网络测试：重新测速 → 结果 + 建议码率。
- 重连、断开、退出串流、休眠主机（确认）；断开/退出回应用页。
- 不显示伪造的主机 CPU/GPU/内存。

### 7.5 操作

- 直通：控制台 60% 不透明度，无焦点环；触摸/Return 进入本地。
- 本地：A 在根层恢复直通；焦点环可见。
- 工具态：A 返回控制台；控制台再按 A 才恢复直通；Y 切换控制台/工具。
- 状态页只读：内容没有按钮/设置行，触摸不会改变任何串流或主机设置。
- 退出串流：确认层；断开连接；回应用页。
- 状态条：直通青点、本地金点、菜单橙点。
- 所有危险操作二次确认；Win+L 必须确认或长按。

#### 触摸板

- 全宽触摸面，点阵背景，金色触点；显示灵敏度（0.8–1.5×）。
- 手势：单指移动、轻点左键、双指滚动、双指轻点右键、双击/长按拖拽；拖拽时按住左键，松手释放。

- ASCII QWERTY + 数字行；5 行，40dp 键高；Esc/Tab/Enter/方向键作为功能键。

- 修饰键：Ctrl / Win / Alt / Shift 粘滞；?123 切符号页；方向键/Enter/Tab/Esc/Backspace。
- 顶部状态：“ASCII 直发 · 无本地拼音” + 最近发送 + “系统”输入法补充入口。

- 修饰键状态在离开键盘/工具/断流时清空。

#### 快捷键

- 4×3 固定 12 个：Ctrl+C/V/X/Z/A、Alt+Tab、Win+D/E、Esc、Tab、Ctrl+Shift+Esc、Win+L。
- 顶部动作条：本地键盘、主机键盘、HDR（Windows HDR 切换，非串流 HDR）、休眠、退出、指纹解锁（P2）。

- MVP 不做自定义宏/快捷键编辑。
- 动作条与快捷键共用同一 `StreamAction` 模型；不引入 V+ QuickAction 的 16 项隐藏动作。


#### 单屏

## 10. 状态与文案

### 通用

- 加载：骨架 + “正在读取主机…”
- 空：一句说明 + 主操作。
- 错误：原因 + 下一步 + 重试。
- 离线：灰色状态点 + “PC 离线”。

### 串流

- 连接：正在连接 / 正在协商画面 / 等待首帧
- 成功：隐藏只读层，显示视频
- 断线：正在重连… / 重连失败
- 退出：确认 / 已断开

### 网络

- EasyTier：未启动 / 需要 VPN 权限 / 等待节点 / 已连接
- 主机不可达：检查 PC 是否在线、IP 是否正确、防火墙/EasyTier
- 配对失败：PIN 错误 / 已配对 / 证书错误

## 11. 焦点顺序

- 主机：Rail → 列表首项 → 详情操作；列表内 Up/Down；Right 进详情。
- 应用：Rail → 首卡 → 应用操作 Sheet；网格 Left/Right/Up/Down。
- 远程：Rail → 状态卡主按钮 → 配置行 → PC 配置/手动添加；配置编辑 Sheet 内循环。
- 设置：7 类分类 → 内容首行 → 行间；Right 进入子页/值，Left 回分类；分类获得焦点即切换。
- 串流：左栏连接摘要/快捷 → 右栏 tab → tab 内容；L1/R1 切 tab；状态页向下保持在页签。
- 工具：工具 tab → 工具内容 → 动作条；A 返回控制台。
- Overlay：只在 overlay 内循环；关闭回触发控件。
