# 上屏规范

> 上屏只负责显示。没有 OSD、按钮、焦点、触摸控件。
> 单屏模式下不存在独立上屏；控制台覆盖层属于唯一宿主。

## 1. 原则

- 播放时：纯 `StreamView`，黑底，视频按比例 letterbox。
- 首帧前：可显示只读待机/连接状态；首帧后隐藏。
- 错误/断线：只读状态 + 文案“请在下屏操作”；上屏不放按钮。
- 视频区外永远纯黑 `#000000`，不跟随主题。
- 上屏不注册 focusable，不接收触摸。
- 不在上屏显示 Toast/HUD/性能浮层；所有统计在下屏。

## 2. 状态

| 状态 | 上屏 |
|---|---|
| 浏览（主机） | 品牌行 + “当前主机”大标题/地址/状态 tags + 显示器示意图 |
| 浏览（应用） | 品牌行 + 主机·应用 + 应用名 + 真实应用图；有 Foundation `hero` 时用 16:9 横图，否则 poster，缺图回退首字母色块 |
| 浏览（远程） | 品牌行 + 虚拟网络 + 网络名 + 本机↔EasyTier↔PC 示意 + 虚拟 IP |
| 浏览（设置） | 品牌行 + 设置分类 + 分类说明 + 前 5 条当前值 + 分类图标 |
| Connecting | 品牌 + 阶段文案（正在连接/协商画面/等待首帧） |
| Streaming | 纯视频 |
| Reconnecting | 保留最后一帧或黑底 + “正在重连” |
| Error | 错误图标 + 一句原因 + “请在下屏重试” |
| Exiting | 黑底/最后一帧，短暂淡出 |

首帧门闸：收到第一帧后隐藏只读层；不要用固定延时猜测。浏览页的上下文由下屏
`DuoTopContext` 提供，只镜像当前选中项，不把下屏状态机搬上屏。

## 3. 布局

- 上屏：约 832×468dp（Duo/Thor 上屏）。
- 顶部品牌行：A1 图标 40dp + `LumaDuo` + `· 页面`；右侧 `READ ONLY`。
- 主区左右分栏：左侧文案（eyebrow + 34sp 标题 + 15sp 副标题 + tags/设置值），右侧 300×230dp 视觉。
- 背景 `StageBg` + 两处低透明度金色/青色光晕；不做大面积主题色。
- 底部左侧“上屏只读 · 下屏操作”，debug 构建右下角显示下屏分辨率。
- 连接状态文字最多 2 行；不显示日志/堆栈。

## 4. 视频 Surface

- `StreamView` / `SurfaceView`，`RESIZE_MODE_FIT`。
- 背景黑；不圆角、不加遮罩、不加渐变。
- `isClickable=false`、`isFocusable=false`。
- HDR：按 V+ 能力设置 display mode/data space；HDR 元数据随流。
- 刷新率：`preferredDisplayModeId` 或 `preferredRefreshRate` 按设置应用。
- 串流中 `keepScreenOn`；退出/断流释放。
- Surface 重建不重建连接；只 attach/detach。

## 5. 浏览页视觉

```text
┌──────────────────────────────────────────────────────────────┐
│ [logo] LumaDuo · 主机                              READ ONLY │
│                                                              │
│                                                              │
│ 当前主机                                 ┌────────────────┐  │
│ GAMING-PC                          │    [monitor]   │  │
│ 192.168.1.20 · 在线 · 已配对           │     ONLINE     │  │
│ [在线] [已配对] [LAN]                    └────────────────┘  │
│ 在下屏选择或操作 · 上屏不接收输入             ▬▬▬  ▬▬▬▬▬▬    │
│                                                              │
│ 上屏只读 · 下屏操作                        下屏 1280×960@320 │
└──────────────────────────────────────────────────────────────┘
```

- 应用页右图为应用真实图：Foundation 主机在 `FsArt` 声明 `hero` 时用 300×169 横图，
  否则用 190×190 poster；两者都取不到时才显示首字母色块。远程页右图为本机↔EasyTier↔PC
  连线；设置页右图为分类图标光晕。
- 标题 34sp SemiBold；eyebrow 11sp 金色大字距；副标题 15sp；tags 使用下屏同一 `DuoChip` 样式。
- 设置页在副标题下展示前 5 条当前值（金色圆点 + 12sp）；不在上屏显示可操作控件。
- 不显示按钮/键位提示；键位提示在下屏 ModeBar。

## 6. 错误

- 图标 48dp + 标题 + 一句原因 + “请在下屏重试”。
- 不显示堆栈、证书、IP 列表、token。
- 不自动循环重试到无限；下屏给明确重试。

## 7. 主题

- 播放/留边：纯黑，不跟随亮暗主题。
- Idle/Connecting/Error：可用主题表面色，但保持深色优先；浅色主题后续再做。
- 上屏不显示焦点环、金色选中态。

## 8. 验收

- [ ] 播放时无 OSD/按钮/焦点。
- [ ] 首帧后只读层消失。
- [ ] 错误时上屏无按钮。
- [ ] 视频比例正确，无拉伸。
- [ ] HDR/刷新率按设置生效（按设备能力）。
- [ ] 切后台/返回后 Surface 重建不崩。
- [ ] 上屏无 Toast/HUD。
