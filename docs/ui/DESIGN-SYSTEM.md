# LumaDuo 设计系统 v0.3

> 适用范围：双屏下屏 `Presentation` 的全部 Compose UI；单屏唯一宿主；上屏只读状态层。
> 目标设备：RP Duo 640×480dp；Thor 约 538×469dp；单屏上屏约 832×468dp。
> 功能入口以 [FEATURE-MAP.md](FEATURE-MAP.md) 为准；页面结构以 [SCREEN-SPEC.md](SCREEN-SPEC.md) 为准。
> 本文是 UI 实现与验收的视觉基准。

---

## 1. 设计原则

1. **视频是主角**：上屏只有画面或只读状态；下屏不抢画面注意力。
2. **一套焦点**：任意时刻最多一个高亮焦点；触摸和手柄操作同一棵树。
3. **模式可见**：ModeBar 常驻显示手柄在控制谁（下屏/直通/菜单）。
4. **近场阅读**：下屏是掌机屏，字号可比 TV 小，但触控目标 ≥44dp。
5. **少即是快**：一屏回答一个问题；二级信息进 tab/sheet。
6. **同系列不同页面**：几何、排版、焦点、rail、ModeBar 延续 bili-duo；信息架构按 LumaDuo 重做。
7. **金色克制**：Lumen Gold 只用于选中、主按钮、品牌和关键状态；大面积保持中性。

## 2. 屏幕与安全区

| 区域 | 物理 | dp | 用途 |
|---|---|---|---|
| 上屏（Duo） | 1920×1080 | 约 832×468 | 仅视频/只读状态 |
| 下屏（Duo） | 1280×960 | 640×480 | 全部 UI、焦点、overlay |
| 下屏（Thor） | 1240×1080 | 约 538×469 | 同上，窄版 |
| 单屏上屏 | 1920×1080 | 约 832×468 | 视频 + 控制台抽屉/覆盖层 |

### 下屏 640×480

```text
640dp
┌──────────────────────────────────────────────┐
│ 16dp 安全边距                                 │
│  ┌──────┬─────────────────────────────────┐  │
│  │ Rail │ AppBar 44dp                     │  │
│  │ 64dp ├─────────────────────────────────┤  │
│  │      │ Content 576×408dp               │  │
│  │      │                                 │  │
│  ├──────┴─────────────────────────────────┤  │
│  │ ModeBar 28dp                            │  │
│  └─────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
480dp
```

- 外侧安全边距 16dp；列表内容左右再留 12dp。
- Rail 64dp；AppBar 44dp；ModeBar 28dp。
- 内容区基准 576×408dp（浏览态）。
- 串流控制台隐藏 Rail，内容 640×408dp（AppBar 44 + ModeBar 28）。
- 触控目标 ≥44×44dp；相邻 ≥8dp。
- 不用系统状态栏/导航栏；edge-to-edge。

### Thor 538×469

- Rail 仍 64dp；内容区约 450dp。
- 主机列表从双列改单列；应用网格 3 列改 2 列。
- 长标题最多 2 行；必要时省略。
- 不把 640 布局等比缩小；按断点重排。

## 3. 色彩

### 3.1 策略

- 深色默认；浅色主题预留 token。
- 层级用表面明度差，不用阴影。
- Lumen Gold 只做选中/主按钮/品牌/关键状态。
- 焦点环不用金色：深色白环、浅色墨环。
- 上屏视频留边永远纯黑。

### 3.4 使用规则

- 次按钮：`surface3` + `text`。
- 危险：`error` 文字 + 12% 背景。
- 状态：成功绿、警告橙、错误红；不要只用颜色，必须有文字/图标。
- 上屏视频区外永远纯黑；待机/预览可用主题色。

## 4. 字体

- 中文/日文：系统 Noto Sans CJK SC。
- 拉丁/数字：系统 Roboto。
- 数字（码率/延迟/计时）用 tabular figures。
- 不引入自定义字体。

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 28/34 | Bold | 空态大标题、品牌字（少用） |
| `titleL` | 20/26 | SemiBold | 页面标题 |
| `titleM` | 16/22 | SemiBold | 区块标题、卡片标题 |
| `bodyL` | 14/20 | Regular | 正文 |
| `bodyM` | 13/18 | Regular | 列表标题、说明 |
| `label` | 12/16 | Medium | tab、chip、按钮 |
| `caption` | 11/14 | Regular | 时间、键位提示 |
| `micro` | 9/12 | Regular | rail 标签、ModeBar 辅助 |

- 卡片标题最多 2 行；列表行标题 1–2 行。
- 最小可读 11sp；rail 标签可用 9–10sp。
- 系统字体缩放 >1.15× 时，主机列表改单列、应用网格降一列。

## 5. 间距、栅格、圆角

- 基准 4dp；常用 4/8/12/16/20/24/32。
- 页面左右 12dp（内容区）；区块 16dp；卡片 8dp。
- 行高：单行 44dp；双行 72–84dp；设置项 48–54dp。
- 主机卡：列表行 88dp；详情卡自适应。
- 应用网格：640 宽 3 列，538 宽 2 列；gap 8dp。
- 圆角：chip 6dp；按钮/输入 8dp；卡片 10dp；面板 12dp；sheet 16dp；头像/圆钮 50%。

## 6. 焦点环

- 内容外 4dp 空隙 + 1.5dp 白环 + 3.5dp 深色分隔边。
- 浅色：墨环 + 白分隔。
- 环画在 `clip` 之前；列表内容留 7dp 透明余量。
- 进入 120ms 淡入；失焦立即消失。
- 不用金色光晕、不用阴影、不用呼吸灯。
- 触控点击也先给目标焦点，再执行。

---

## 7. 图标

- 基础：Material Symbols Rounded，weight 400，24dp 网格。
- rail 22dp；行内 18dp；主按钮 24dp；空态 48dp。
- 自绘串流语义图标：
  - 主机/显示器
  - 应用网格
  - 地球/网络
  - EasyTier 节点/链路
  - 手柄/直通
  - HDR/刷新率/码率
  - 配对 PIN/二维码
- 图标按钮必须有 contentDescription；关键操作配文字。

## 8. 组件

### 8.1 Rail

- 宽 64dp，`surface2`，右侧 1dp outline。
- 顶部 40dp LumaDuo 品牌标：直接使用最终 A1 矢量（原型 SVG / 生产 VectorDrawable）缩放，不重绘小尺寸版本。4 个入口：主机/应用/远程/设置。
- item 56dp：22dp 图标 + 9–10sp 文字常驻。
- 选中：3dp 金色竖条 + 图标/文字 `accentInk`；焦点再加环。
- 底部主题切换（设置页也可）。

### 8.2 AppBar

- 高 44dp；左标题 `titleL`；右 1–2 个动作。
- 下边框 1dp outline；不做大标题折叠。

### 8.3 ModeBar

- 高 28dp，全宽，`surface1`，上边 1dp outline。
- 左：7dp 圆点 + 10sp 状态；中：上下文提示；右：2–3 个键位。
- 不接收焦点、不可点击。
- 状态色：本地金、直通青、菜单橙、无手柄灰。

### 8.4 主机卡 / 行

```text
┌──────────────────────────────────────┐
│ ● 书房台式机                 LAN     │
│   192.168.1.20 · 已配对 · 2 分钟前    │
└──────────────────────────────────────┘
```

- 高 88dp；`surface1`，无描边；选中 `accentSoft` + 金边。
- 状态点：在线绿、离线灰、连接中金/脉冲。
- 右侧标签：LAN/远程/收藏。
- 详情面板：名称、地址、状态、最近连接、操作按钮。

### 8.5 应用卡

- 3 列（640）/2 列（538）；图标 56dp 圆角或方形；标题 1 行；副标题 1 行。
- 选中金边 + 12% 背景；按下 scale 0.97。
- 无应用图标时用首字母/几何占位，不拉破图。

### 8.6 Tab / Chip

- Tab 高 36dp；选中 `accentInk` + 2dp 金下划线；未选中 secondary。
- Chip 高 28dp；`surface3`；选中 12% 金 + 金边。
- 肩键切换与点击一致。

### 8.7 按钮

- 主按钮 44dp 高，金填充 + `onAccent`。
- 次按钮 44dp，`surface3` + text。
- 圆钮 40/56dp；焦点 2dp 金边 + 外环。
- 危险按钮 error 文字 + 12% 背景；需确认层。

### 8.8 状态/统计

- 码率/延迟/丢包用 tabular；`caption`/`micro`。
- 三档颜色：正常 text/secondary、警告橙、错误红。
- 不使用红绿点单独表达；配文字。

### 8.9 键盘

- 数字键盘：4×3 + 退格/清空/完成；键 44dp。
- ASCII 全键盘：QWERTY + 数字行 + Shift/符号/退格/空格/完成；键 36–40dp。
- 焦点环在键内；按键按下 80ms。
- 面板 `surface2` + 1dp outline + 16dp 圆角；高度 ~220dp（数字）/ ~260dp（全键盘）。
- 这是本地输入键盘；串流远端 ASCII 键盘见 8.10，二者不共用拼音/候选词逻辑。

### 8.10 串流工具

- 控制台/工具切换条 30dp；工具 tabs 34dp；工具内容占满 616dp 宽。
- 触摸板：点阵 18dp，触点 8dp 金；按钮 38dp；灵敏度 0.8–1.5×。
- 键盘：5 行，键高 40dp，键距 5dp；特殊键/修饰键用 `surface3`，选中金 12%。
- 快捷键卡：4×3，`surface1` + outline；键名 mono 10sp 金色；危险项 error 描边。
- 焦点环：键盘键使用 2dp 紧凑白环，避免相邻键重叠；其他工具元素用标准焦点环。
- 工具态不显示 Rail；A 回控制台，控制台再 A 回直通。
- 单屏工具 P1：抽屉升到 68% 或全屏工具层，复用同一组件。

### 8.11 状态页（只读，默认）

- 5 个 tab：状态/画面/音频/输入/连接；状态置首并默认。
- 顶部状态条：`良好` 绿点 + `LIVE` 会话时长 + `只读` 金标。
- 三张 52dp KPI 卡：帧率 / 网络延迟 / 实测码率；数值 mono 17sp，副行 6.5sp。
- 60 秒趋势卡 44dp：延迟金线、码率青线；仅趋势，不标绝对值刻度。
- 明细 2×2 信息矩阵，单元格 44dp：画面 / 链路 / 本机 / 主机；图标 11dp + 主值 mono 11sp + 次值 7sp；主机实时负载不可得写“未提供”。
- 底部一句诊断提示 + 数据来源；示例数据必须标“示例数据”。
- 内容 **不注册 focusable**；唯一焦点是“状态”tab；向下不进入内容。
- 主机段 STATIC/UNAVAILABLE 不画假进度条；不提供重试按钮，自动刷新。
- 文案说明“只读，不会修改设置”；不伪造 CPU/GPU/内存负载。

### 8.12 Overlay / Sheet

- 全部 Compose overlay，不用系统 Dialog。
- 居中 panel：宽 360–420dp，`surface2` + outline + 16dp 圆角。
- 右侧 sheet：宽 320dp，仅左圆角。
- 底部 sheet：最大 280dp。
- scrim 66%；焦点陷阱；B/A 关闭优先级一致。

### 8.13 Toast / HUD

- 轻提示：ModeBar 上方 16dp，`surface2` + 8dp 圆角，2s。
- 音量/亮度/码率 HUD：200×48dp，1.5s。
- 上屏永远不显示 Toast/HUD。

### 8.14 空态/加载/错误

- 空态：48dp 图标 + titleM + bodyM + 主按钮（可选）。
- 加载：骨架屏/阶段文案，不用全屏 spinner。
- 错误：error 图标 + 人话 + 重试；不显示堆栈。

### 8.15 设置行与子页

- 父级：左侧 104dp 分类列（7 行 × 44dp），右侧 476dp 子页列表。
- 子页行 44dp：标题 bodyM + 说明 micro + 值/开关/滑杆；左右 8dp 内边距；行间 2dp。
- 值列右对齐，金色 `bodyM medium`；只读值用 secondary，不画金色。
- 可调行显示 `‹ ›`；A/→ 增加，← 减少；滑杆行 Right 进入滑杆，Left/Right 调值，B 退出。
- 开关行：44×24dp 轨道，选中金色；开关本体不单独抢焦点，整行可聚焦。
- 子页入口行：右侧 `›`；A 打开子页；子页返回后焦点回入口行。
- 子页顶部：返回箭头 + 面包屑（设置 / 画面 / 串流画质）+ 当前值；32dp 高。
- 分类获得焦点即切换（D-027）；列表滚动时焦点自动 brought into view。
- 7 类分类：画面/音频/输入/网络/主机/界面/关于。

### 8.16 主机详情与操作 Sheet

- 宽版：左列表 320dp + 右详情 244dp + 12dp gap；窄版详情用底部 Sheet。
- 详情卡分组：身份（名称/状态/地址/配对）、主操作（最多 2 个 44dp 按钮）、次操作（网络测试/详情）、更多（危险项红色）。
- 主机操作 Sheet：底部 Sheet 最大 360dp，分组行 44dp；危险区与主区分隔 1dp outline。
- 运行中徽章：金色 6dp 点 + “运行中” micro；未配对锁图标；离线 45% alpha。
- 详情内不重复 AppBar 已有动作；删除/休眠/退出统一确认层。

### 8.17 远程页

- 状态卡：左侧状态点 + 状态文案 + 主按钮；下方 2×2 摘要（网络名/IP/节点/延迟）。
- 配置卡：行 40dp；密钥显示 `••••••••`，A 长按 600ms 或确认层后显示 8 秒。
- 编辑 Sheet：宽 420dp；网络名/密钥/虚拟 IP 输入框 + Peer 多行；数字/ASCII 键盘；保存/取消。
- 高级 flags 子页：2 列开关网格，默认折叠。
- PC 配置按钮：复制 TOML / 显示 QR；QR 320×320dp + 说明；复制包含密钥时先确认。
- 手动添加：一行 IP 输入 + 添加按钮；预填 10.0.0.2。
- 错误状态：VPN 拒绝/启动失败/等待节点，保留重试，不显示密钥。

### 8.18 串流控制台 tabs

- 顶部切换条 30dp：[控制台][工具]；激活项金色下划线；Y 切换。
- tab 行 34dp：状态/画面/音频/输入/连接；选中金色 2dp 下划线；L1/R1 或 ←/→ 切换。
- 左摘要 220dp：主机名、1080p60、延迟、码率、HDR、输入模式、“本地菜单”按钮。
- 右内容 384dp：行 40–44dp；分组标题 24dp；状态值 mono。
- 状态页：KPI 52dp ×3 + 趋势 44dp + 2×2 矩阵；无 focusable。
- 画面/音频/输入/连接：可调行 + 即时状态；需重连项金色“应用并重连”chip。
- 底部 ModeBar：直通青/本地金/菜单橙 + Return/Back 提示。
- 工具态占满 616dp；工具 tabs 34dp + 内容 + 动作条 40dp。
- 直通态控制台 60% 不透明度、无焦点环；本地 100%。

### 8.19 确认层 / 输入层

- 确认层 360×180dp：标题 titleM、后果 bodyM、[取消][确认] 两个 44dp 按钮；危险确认金色描边，默认焦点取消。
- 错误层 360×220dp：标题、原因、下一步；错误码折叠在“详情”。
- PIN 配对：4 个 56dp 数字格，金色 32sp mono；状态行 12sp；[取消][重试]。
- 数字键盘：4×3 + 退格/清空/完成；键 44dp；用于 IP/端口/PIN。
- ASCII 输入：复用工具键盘组件；输入框内显示光标，不弹系统 IME（系统 IME 仅触摸补充）。
- QR：320×320dp 白底 + 8dp 静区；下方说明与复制按钮；无摄像头时隐藏扫码入口。
- Toast/HUD 与确认层不同时出现；确认层打开时暂停 Toast。

## 9. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 焦点进入 | 120ms | FastOutSlowIn |
| 按下 | 80ms | LinearOutSlowIn |
| 页面切换 | 180ms | FastOutSlowIn |
| Sheet | 220ms | FastOutSlowIn |
| Dialog/Overlay | 160ms | FastOutSlowIn |
| Toast | 150ms in / 150ms out | Linear |

- 播放中不做持续动画；尊重系统“移除动画”。
- 不做焦点呼吸、背景视差、3D 翻转。

## 10. 响应式

- 640×480：3 列应用、双列主机、双栏详情。
- 538×469：2 列应用、单列主机、详情覆盖层。
- 单屏 832×468：左列表/右详情或顶部 tab + 单列；串流时视频全屏 + 抽屉。
- 字体缩放：标题降行、网格降列。
- 不用百分比写死列数；用断点 + `LazyVerticalGrid`。
